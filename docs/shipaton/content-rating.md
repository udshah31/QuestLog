# QuestLog — Content rating (IARC questionnaire)

Play Console → *Policy and programs → App content → Content rating → Start questionnaire*.
The wording of individual questions shifts over time; the answers below follow what's in the app.

## Setup

| Field | Answer |
|---|---|
| Email address | your contact email (IARC sends the certificate there) |
| Category | **All Other App Types** — QuestLog is a productivity / digital-wellbeing app with game-like rewards, not a game. (If you file it under the *Game* category instead, answer the same way.) |

## Questions

| Topic | Answer | Why |
|---|---|---|
| Violence (realistic, fantasy, blood, gore) | **No** | No combat or violence. Buildings and quests only. |
| Fear / horror | **No** | |
| Sexuality / nudity | **No** | |
| Crude humour | **No** | |
| Language (profanity) | **No** | All copy is fixed text written by us. |
| Controlled substances (drugs, alcohol, tobacco) | **No** | |
| Gambling — real or simulated, loot boxes, random paid rewards | **No** | Gold comes only from time saved and daily quests; nothing random, nothing bought with money except Pro. |
| Users interact or exchange content with each other (chat, voice, UGC visible to others) | **No** | No in-app social features. The reason typed for a Mindful Unlock is seen only by the user and the AI check. |
| Shares the user's current physical location with other users | **No** | No location access at all. |
| Digital purchases | **Yes** | QuestLog Pro subscription via Google Play. |
| Unrestricted internet access / web browser | **No** | |
| AI-generated content shown to users | **No** | The AI returns only a score and a category; the text the user sees is fixed app copy ("5 minutes, no charge.", "That sounds like drifting — it'll count today."). |
| Promotes or is primarily about a restricted topic (medical, political, etc.) | **No** | |

**Share card:** exporting the skyline image through Android's share sheet hands it to another
app the user chooses — it isn't in-app user interaction, so it doesn't change the answers above.

## Expected result

**Everyone / PEGI 3 / USK 0** (plus the "In-App Purchases" interactive element). If the result
comes back higher, check the gambling and user-interaction answers first.

## Related App content items

- **Target audience and content:** age groups **18 and over** (optionally 13–17 as well).
  Don't include under-13 groups — that brings in the Families policy. Answer **No** to
  "could unintentionally appeal to children".
- **Ads:** **No, my app does not contain ads.**
- **News app:** No. **Government app:** No. **Financial features:** None.
- **Health apps:** QuestLog is digital wellbeing, not a health or medical app → **No** health
  features.
